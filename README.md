# Web Penetration Testing

A collection of practical web application penetration testing labs, exploitation techniques, post-exploitation activities, and security assessments performed in a controlled lab environment.

This repository documents hands-on exercises focused on identifying, exploiting, and understanding common web application vulnerabilities and attack techniques.

---

## Repository Objectives

- Develop practical web penetration testing skills.
- Understand common web application vulnerabilities.
- Practice exploitation techniques in a safe environment.
- Document attack methodologies and remediation strategies.
- Build a professional cybersecurity portfolio.

---

## Projects

| Project | Description |
|----------|-------------|
| Netcat Reverse Shell | Establishing reverse shell access using Netcat. |
| Powercat Reverse Shell | PowerShell-based reverse shell using Powercat. |
| Msfvenom Reverse Shell | Payload generation and reverse shell access using Msfvenom. |
| File Upload Vulnerability | Exploiting insecure file upload functionality to achieve remote code execution. |
| File Transfer Techniques | File transfer, SMB shares, credential capture, and password recovery techniques. |

## Methodology

Each project follows a structured methodology:

1. Objective Definition
2. Environment Preparation
3. Vulnerability Identification
4. Exploitation
5. Verification
6. Security Impact Analysis
7. Detection Opportunities
8. Remediation Recommendations
9. Key Learning Documentation
